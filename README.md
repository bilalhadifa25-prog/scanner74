# الماسح 74 — Scanner 74

ماسح مستندات شخصي يعمل دون إنترنت (PWA). كل المعالجة تتم على الجهاز، ولا يُرفع أي شيء إلى خادم.

## ما يتضمنه الإصدار 1.0 (المرحلة الأولى)
- التصوير بكاميرا الهاتف (مفرد أو متعدد) مع رصد حواف الورقة مباشرة، والفلاش إن توفّر
- استيراد صور من المعرض أو الملفات
- قصّ الحواف بأربع زوايا وأربعة أضلاع مع عدسة تكبير، وتصحيح المنظور، والتدوير، والكشف التلقائي
- المرشحات: الأصل، سحري، محسّن، إزالة الظل، رمادي، أبيض وأسود + السطوع والتباين، وتطبيقها على كل الصفحات
- مستندات متعددة الصفحات: إضافة، حذف (مع تراجع)، ترتيب، إعادة تعديل أي صفحة، إعادة تسمية
- تصدير PDF (A4 / Letter / بحجم الصورة) أو صور JPG (ملف ZIP عند التنزيل)، بثلاث درجات جودة، **بدون علامة مائية**، ومشاركة مباشرة
- مكتبة محلية مع بحث، العربية والإنجليزية، فاتح وداكن، ويعمل دون إنترنت بعد أول فتح

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (مثلاً `scanner74`) وارفع كل محتويات هذا المجلد إلى جذره.
2. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
3. افتح الرابط `https://اسمك.github.io/scanner74/` من الهاتف:
   - أندرويد (Chrome): القائمة ← «تثبيت التطبيق».
   - آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

الكاميرا تحتاج رابط https (وGitHub Pages يوفّره). فتح الملف مباشرة من الجهاز لن يشغّل الكاميرا.

## عند تحديث الملفات
غيّر قيمة `VERSION` في `sw.js` حتى تصل النسخة الجديدة للأجهزة المثبَّت عليها التطبيق.
